## 📊 Optimization Fitness Criteria

### Primary Metrics (in order):

1. **Net Profit > 0** (must be profitable!)
2. **Profit Factor > 1.3** (avoid overfitting if > 3.0)
3. **Max Drawdown < 20%** (risk control)
4. **Trade Count > 30** (statistical significance)
5. **Win Rate: 25-45%** (realistic for 4:1 RR)

### Warning Signs:

❌ **Profit Factor > 3.0** → Likely overfitted
❌ **Win Rate > 60%** → Too good to be true
❌ **Trade Count < 30** → Not enough data
❌ **Top 2-3 trades = most profit** → Lucky trades, not system
